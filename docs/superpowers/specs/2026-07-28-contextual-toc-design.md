# 문맥형 목차(Contextual TOC) 설계

## 목표

게시글의 목차를 읽기 흐름에 맞게 제공한다. 데스크톱에서는 본문 우측에 고정하고, 모바일에서는 본문 상단에 간결하게 유지한다.

## 동작

### 데스크톱 (`md` 이상)

- `remark-toc`가 생성한 본문 목차는 접근성 및 원본 링크 구조를 유지하되 화면에서는 숨긴다.
- 게시글의 제목(`h2`, `h3`)을 읽어 우측 고정 목차를 렌더링한다.
- 초기 상태에는 최상위 항목(h2)만 보인다.
- 스크롤로 활성 h2가 바뀌면 해당 항목의 h3만 펼친다.
- 목차에 키보드 포커스가 있거나 마우스를 올린 동안에는 모든 항목을 펼친다.
- 활성 링크에는 시각적 강조와 `aria-current="location"`을 적용한다.
- 링크를 선택하면 대상 제목으로 부드럽게 이동한다.

### 모바일 (`md` 미만)

- 기존의 본문 내 TOC를 유지한다.
- 최상위 항목(h2)만 표시하고, 하위 목록(h3)은 숨긴다.
- 우측 고정 목차는 렌더링하지 않는다.

## 구성

- `src/components/content/ContextualToc.astro`: 데스크톱 목차 컨테이너와 클라이언트 동작.
- `src/pages/[slug].astro`: 콘텐츠 렌더링 영역에 컴포넌트를 배치한다.
- `src/styles/content.css`: 고정 위치, 확장 상태, 모바일 TOC의 깊이 제한을 정의한다.

목차 데이터는 런타임에 렌더링된 게시글의 제목 요소에서 수집한다. 따라서 Markdown 플러그인 설정을 변경하지 않으며, 제목 ID와 기존 TOC 링크는 동일하게 유지된다.

## 접근성 및 예외

- 제목이 없거나 h2가 없으면 데스크톱 목차를 숨긴다.
- `IntersectionObserver`를 사용할 수 없는 환경에서는 링크 목록을 유지하되 활성 상태 갱신만 생략한다.
- 마우스뿐 아니라 키보드 포커스에서도 전체 목차를 펼쳐 조작 가능하게 한다.

## 검증

- 데스크톱에서 고정 위치, 활성 항목 변경, 자동/호버/포커스 확장을 확인한다.
- 모바일에서 본문 TOC가 h2 링크만 표시하는지 확인한다.
- 제목 링크 이동, 키보드 탐색, 제목 없는 짧은 글을 확인한다.
